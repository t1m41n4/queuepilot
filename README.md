# QueuePilot

QueuePilot is a web-based smart queue management system designed to reduce customer waiting times and improve branch operations through deterministic queue management, real-time updates, and an AI-powered Queue Operations Assistant.

## Features

- Join queues remotely
- Live queue status updates via WebSockets
- Deterministic Queue Engine
- Branch recommendations based on operational metrics
- AI-powered Queue Operations Assistant
- Staff dashboard for queue management

## Technology Stack
